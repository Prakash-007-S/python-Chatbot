# Python AI Chatbot 🤖

A beginner-friendly AI chatbot built using Python and Ollama (LLaMA 3).

## Features
- Free & offline
- Uses local LLM (LLaMA 3)
- Terminal-based chatbot
- Conversation memory

## Requirements
- Python 3.9+
- Ollama
- llama3 model

## How to Run

```bash
pip install langchain langchain-community langchain-ollama
python chatbot.py
